Subscribe (auto-updating)

To have your calendar refresh automatically as games change, subscribe to a team's file URL instead of importing it. Copy the team's Download link above to get its .ics URL.

Google Calendar:

  1. Open Google Calendar.
  2. Next to Other calendars, click + → From URL.
  3. Paste the team's .ics URL and click Add calendar.

Apple Calendar: File → New Calendar Subscription, then paste the same URL.

One-time import

  1. Download a team's .ics file above.
  2. In Google Calendar, go to Settings → Import & export.
  3. Select the file, choose a calendar, and click Import.
